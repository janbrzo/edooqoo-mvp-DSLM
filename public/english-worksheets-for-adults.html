Try It: Business English Task for Adult Learners (B2)

A short task in the style Edooqoo produces, set in a real adult context: emails, meetings and negotiations. Use it as is in your next lesson, or generate an editable version tuned to your learner.

  1. Choose the more professional option: "Send me the file now." / "Could you send me the file by noon?"
  2. Complete: "I'm afraid we can't ____ that price." (accept / take)
  3. Complete: "Let's ____ up the main points before we finish." (sum / close)
Answer key

1. Could you send me the file by noon?
2. accept
3. sum

Common Adult Learner Errors and How to Fix Them

What learners sayCorrect formTeaching note
I want that you send me the offer.I would like you to send me the offer.want and would like take object plus infinitive.
Please find in attachment the invoice.Please find the invoice attached.Fixed email phrases follow English word order.

If one of these errors keeps returning after practice, treat it as a repair point rather than a reason to move on.
