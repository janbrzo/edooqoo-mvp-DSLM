Try It: Mixed error review Task for Adult Learners (B1)

A short task in the style Edooqoo produces, set in a real adult context: a learner's own recurring errors from the last two lessons. Use it as is in your next lesson, or generate an editable version tuned to your learner.

  1. Correct the sentence: "I am working here since March."
  2. Correct the sentence: "We discussed about the new budget."
  3. Correct the sentence: "If the client will agree, we start in May."
Answer key

1. I've been working here since March.
2. We discussed the new budget.
3. If the client agrees, we will start in May.

Common Adult Learner Errors and How to Fix Them

What learners sayCorrect formTeaching note
I am working here since March.I've been working here since March.Duration up to now needs a perfect form.
He explained me the process.He explained the process to me.explain takes the person after to.

If one of these errors keeps returning after practice, treat it as a repair point rather than a reason to move on.
