One-to-One Lesson Planning

Task-Based Worksheets for Adult One-to-One English

By Jan Brzostowski Reviewed by Martha, ESL Methodology Reviewer Published 2025-06-17 Updated 2026-06-15

Direct answer: A task-based worksheet for adult one-to-one English should prepare a meaningful outcome, reduce only the barriers that prevent an initial attempt, let the learner complete the task with genuine choices, and use the resulting language evidence for focused follow-up.

Start with the adult performance, not the topic list

A worksheet is not task-based simply because it contains a role-play. The learner must use language to reach an outcome, make decisions, and respond to information that is not fully predetermined.

In adult one-to-one teaching, the useful unit of planning is a performance in context. The tutor defines what the learner must do, the audience or reader, the pressure or constraint, the support currently available, and the evidence that will count as independent success. This prevents a broad topic from becoming a sequence of school-like exercises with no clear transfer.

The learner's profession or interest can make examples relevant, but relevance alone is not personalization. The material must respond to current evidence and make the next teaching decision easier. A lesson should therefore leave the tutor with a defensible answer to three questions: what changed, what still requires support, and what should happen next.

Evidence to collect before planning

Use a small evidence set. The aim is not to document everything about the learner; it is to retrieve only the information that changes the objective, task, support, feedback, or sequence.

  • Meaningful outcome. Define what must be decided, arranged, explained, solved, selected, or produced beyond correct language.
  • Information conditions. Create a reason to exchange, interpret, or negotiate information rather than recite known lines.
  • Learner readiness. Check whether the learner has enough language and domain understanding to attempt the task without complete scripting.
  • Post-task priority. Plan how evidence will select one useful language focus instead of preteaching every possible phrase.

When the evidence is weak or contradictory, use a short diagnostic attempt before adding new content. A direct sample is usually more useful than asking whether the learner understands a rule or feels confident. Confidence can affect participation, but it does not replace observable performance.

Teaching decision

Use a task when the learner can attempt the outcome with available resources. Repair prerequisites first when the task would measure only missing basic knowledge or unfamiliar professional content.

For this topic, make the next lesson decision from the stated criterion and current evidence rather than from content coverage.

The decision should be narrow enough to test in the next task. Avoid labels such as 'work on fluency' or 'improve grammar.' Name the communication function, the relevant language or strategy, the conditions, and the quality criterion. This makes the plan editable when the learner's first attempt produces different evidence.

A practical one-to-one workflow

The following sequence protects teacher judgment while making preparation repeatable. Each stage has a specific evidence function, so an activity is not included merely because it is familiar or visually attractive.

  1. 1. Set the outcome and roles

    Give each participant a purpose, relevant information, and a condition that makes communication necessary.

  2. 2. Activate essential resources

    Retrieve only the minimum concepts, language, or strategy required for an initial attempt.

  3. 3. Run the task without overcorrection

    Let the learner complete the meaning-focused attempt while the tutor records representative evidence.

  4. 4. Focus on one language need

    Analyze the pattern that most affected outcome, clarity, tone, or efficiency.

  5. 5. Repeat with changed conditions

    Alter a detail, response, constraint, or stakeholder so the learner must adapt the improved capability.

Do not force every lesson through the same number of stages. If the opening retrieval shows independent control, shorten repair and move to transfer. If a prerequisite is missing, reduce the target rather than disguising the gap with permanent prompts.

Adult one-to-one worked example

Student context
A B1 project manager must negotiate priorities when two teams request the same specialist.
Evidence
The learner can state preferences but cannot ask for constraints or propose a trade-off.
Continue, repair, or advance
Use a decision task with conflicting information, then focus on clarification and conditional proposals.
Lesson objective
Elicit constraints, compare consequences, and agree a temporary allocation with owners and review date.
Activity sequence
Retrieve core questions, inspect role cards, complete the negotiation, analyze two breakdowns, rehearse alternatives, then repeat with a new deadline.
Evidence to collect next
Check whether the second agreement contains rationale, owner, duration, and review condition without tutor prompting.

This is a worked example, not a claim about a real student's outcome. Its purpose is to show how context and evidence become a bounded teaching decision without inventing results.

Material and worksheet design

The worksheet should support the task, not script it. Provide roles, information, constraints, and success criteria while leaving enough uncertainty for the learner to choose language.

A useful worksheet creates a path from retrieval or diagnosis to supported rehearsal and independent transfer. Instructions should be clear on the learner's actual device, examples should be credible for an adult, and answer keys or model responses should be reviewed before use. When an exercise can be completed correctly without engaging the target decision, it is not valid evidence for that objective.

Teacher control remains necessary. Generated or reusable material can reduce mechanical preparation, but the tutor still owns factual accuracy, appropriacy, level, sequencing, correction priorities, and the response to live learner evidence. The material should be easy to edit when the first attempt changes the plan.

What to avoid

  • Calling a fully scripted dialogue a communicative task.
  • Preteaching so much language that the initial evidence disappears.
  • Using a professional scenario that depends on specialist knowledge the learner has not supplied.
  • Ending after task completion without focused analysis and repeat performance.

These failures have the same root cause: the visible activity replaces the teaching decision. A professional adult lesson should make the reason for each stage clear to the tutor and, where useful, to the learner.

Evidence for the next lesson

Record task completion, communication strategy, breakdowns, target-language use, support, and whether focused post-task work improves a second attempt.

Write evidence in comparable terms: task, conditions, support, observed performance, consequence, and next decision. A short statement such as 'completed the request independently but omitted the deadline in both attempts' is more actionable than a page of undifferentiated notes. Revisit the target after a delay before treating immediate success as stable learning.

Frequently asked questions

What makes a worksheet task-based?

The learner uses language to reach a meaningful outcome with choices, information, and a result beyond displaying correct forms.

Can grammar be taught in a task-based lesson?

Yes. Grammar can be retrieved before the task or addressed after evidence shows that it limits the outcome.

Should the tutor correct during the task?

Usually record evidence and protect task completion, intervening only when communication stops or the task purpose requires immediate repair.

Why repeat the task?

A changed repeat lets the learner apply focused feedback while preventing simple memorization of the first exchange.

Are task-based worksheets suitable for A1 learners?

Yes, when the outcome is bounded, support is visible, information is simple, and the language demand matches current control.
