# AI Search Baseline Template

## Problem
AI-search observations are easy to distort if results are summarized loosely. The baseline needs a dense, factual table that future agents can compare across dates.

## Edooqoo.com Solution
Record one row per engine-query pair using the fixed query set. Do not write inferred visibility or expected visibility. Record only what the engine showed during manual measurement.

## Technical Mechanics
- Copy this template into `docs/seo/ai-search-baselines/YYYY-MM-DD-baseline.md`.
- Fill every row after manual checking.
- Use `none` when no Edooqoo URL is cited.
- Use `no change`, `strengthen page`, `add FAQ`, `add internal link`, or `fix metadata` for next action.
- Do not automate answer scraping in this sprint.
