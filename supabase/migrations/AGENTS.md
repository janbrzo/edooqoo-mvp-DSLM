## Homework lifecycle & DSLM events

- "Homework waiting for review" is decided only by `isHomeworkAwaitingReview` in `src/lib/homework/reviewState.ts`, and every review entry point links to `/homework/:id/review` (the notification bells through `notificationPath` in `src/lib/notifications/notificationRoute.ts`, never to the student share link) — because the dashboard, timeline and homework list used to disagree and the review page was unreachable after the first review; a homework is open only while `completed_at` is NULL (enforced in SQL by `save_homework_answer`, `submit_homework_answers` with the `homework_closed` error, an idempotent `mark_homework_completed_internal` that never overwrites a student return, and the owner-only `reopen_homework`), and its lifecycle (open, submitted, reviewed, closed) is read only by `homeworkState` — because Mark done used to leave the homework writable and a late submit never reached the review queue.

- A homework's exercise snapshot (answer keys included) leaves the database only through `get_homework_exercises_by_share_token` (owner teacher, or share token + assigned email) and the link-only `get_homework_by_share_token` returns exercises, image and audio just to the owner (`20261028100000`, `20261028100100`; the student page reads them in `HomeworkPage` after `verifyStudentEmail`) — because a bare link used to carry every answer key and the page only blurred it.
- A closed homework item the key leaves unrated ("review") is decided only by the owner teacher through `set_homework_item_verdict` (`20261028110000`, now a wrapper of `set_homework_item_score`, `20261028140000`: ratings of that question become 100 or 0 with `source: 'teacher'`, 0-100 for open answers listed by `findItemsToScore`; exercise mastery = share of rated questions at 50 or more for closed, the mean for open; only a row the server finished grading can be rated), listed by `findItemsToCheck` (`src/lib/homework/reviewItems.ts`) on `/homework/:id/review`, never by the browser or the AI — because unrated items never reached the DSLM and word-order exercises showed an inflated mastery.
- What the student sees after "Send review" (the teacher's per-exercise comments and decisions on unrated items) is read only through `get_homework_review_by_share_token` (share token + assigned email, null until `reviewed_at`; `20261028120000`) and shown by `HomeworkPage`, and the teacher toast may promise only that — because the review used to claim a delivery that had no student-facing read.
- A returned homework is redone only through `request_homework_redo` (owner teacher, `20261028150000`): the returned attempt (answers, ratings, AI result, comments) is archived in `homework_attempts` first, then the answers reset and `attempt` increases; the first attempt's DSLM events stay until the second one is submitted and evaluated — because a retake used to be impossible and a reset without an archive would erase what the student first did.
- Answer -> event triggers delete and re-insert only events of their own `event_source` (homework/worksheet) and skip writes that change none of answers, item_evaluations, audio_answers, mastery, eval_trigger, exercise_type; skill metrics recompute on INSERT, UPDATE and DELETE of `student_events`, Mark done is saved/undone only via `save_mark_done_evaluation` / `delete_mark_done_evaluation`, is prefilled only by `calculateInitialMasteryForItem` (shared key verdict, 0-100) and supersedes the student's worksheet ratings of the whole exercise in `compute_skill_metric` (v3, `20261015090000`, plus `20261017100000`: one data point per event and skill, events with `superseded_at` ignored, advisory lock per metric, `insufficient_data` below 4 points and allowed by `student_skill_metrics_trend_check`, ascending history with timestamps, a reopened Mark done prefills the saved teacher ratings); a changed worksheet answer clears its `ai_evaluation` and an unchanged re-save keeps `ai_alternative` raises — because teacher evaluations were wiped by later student saves, metrics drifted from events and RLS silently dropped direct teacher updates, a teacher correction was averaged with the verdict it corrected, a 10-item exercise counted ten times, and stale AI scores survived edits.
